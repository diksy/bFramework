## 3. Kelas uji yang dinilai bersih (statis, rujukan kode)
- **CSRF** semua POST termasuk `/install/canary` dan `/auth/step-up`: `CsrfMiddleware.php:26-41`; satu-satunya `csrf:false` = back-channel (`SsoDriver.php:86`, SSO-16).
- **SQLi**: allowlist identifier + binding (`Runtime/Query.php:189-238`), `normalizeSort`.
- **IDOR / admin**: `constrain()` di semua query repo; admin lewat Authorizer + StepUp.
- **Upload**: finfo + whitelist, re-encode GD, nama acak di luar docroot, `nosniff` + CSP sandbox.
- **Open redirect / Host**: `Response.php:151-165`, `SsoDriver::safeNext`, `StepUp::safeNext` (regex jalur admin), HostGuard selalu dipasang.
- **Enumerasi / sesi / XSS / SSRF / CRLF / .htaccess statis**: tidak berubah sejak laporan awal; `data-url`/`data-content` kanari di-escape template dan berasal dari server.
- **Kanari endpoint** (`/install/canary`, anonim pra-instal): CSRF, rate limit, 404 setelah instal, maksimal satu berkas kanari (nama/isi acak, tanpa input pengguna di jalur berkas), bukti hanya bila kanari tertunda ada. Penyalahgunaan tersisa: menghapus kanari pemilik dengan `blocked=0` (DoS ringan instalasi, dibatasi rate limit).
- **Rahasia di log baru**: step-up/2FA/kanari/back-channel hanya mencatat user_id, alasan generik, nama kelas; semua melewati Redactor; tidak ada token/secret/password.

## 4. Pemindaian ulang (2026-10-24)
- Cakupan: diff SEC-1..SEC-4 (commit 084ae59, ad74696, 3f94dde, a118187) dibaca langsung per berkas (git tidak diizinkan hook): Installer, InstallController, install.tpl, install-canary.js, OidcClient, BackchannelHandler, SsoDriver, bootstrap.php, HttpClient, StepUp, AuthManager, AuthMiddleware, AdminController, UpdateController, LocalDriver, SecurityHeaders, Kernel, ErrorHandler, RotatingFileLogger, TransportPolicy, Request, PageController, assets/.htaccess, index.php, build-release.php, UpdateKey.
- semgrep dan gitleaks: hasil identik dengan laporan awal (hanya S17); tidak ada temuan atau rahasia baru.
- Regresi yang diperiksa dan **tidak** ditemukan: open redirect lewat `next` step-up, bypass step-up lewat `amr` (amr hanya dari driver, difilter), spoofing `X-Forwarded-Proto` (nilai terakhir + CIDR), penulisan berkas bebas lewat kanari, fail-open limiter back-channel (terpasang di bootstrap), header CSP handler tertimpa.
- Baru: S20, S21 (rendah), S22 (info). Tidak ada yang memblokir rilis; disarankan satu tugas kecil (S21 + S20b, lalu S20a dan S4 sisa) sebelum/sesudah rilis sesuai keputusan pemilik.
